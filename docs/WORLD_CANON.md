## 1 时间

- 年份口径只有一种：**第一纪元第 N 年**（界面写「第一纪元 · 第 N 年」）。每一世都从第 1 年开始，主角 16 岁。
- 第一纪元共一万年，每百年一章（B001—B100），章名和五域局势取自百年总表。
- 第一纪元结束（第 10000 年）后进入第二纪元，由母题库拼装，称「无尽纪元」，是通关后的长线。
- 灵气、修凡消长随章变化，影响修炼速度、坊市物价、宗门实力。

## 3 境界（十境保留，只改名一处）

炼气（九层）→ 筑基 → **结丹**（原「金丹」改名）→ 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 真仙。
- 原典常识只讲到元婴；元婴以上是世人不知的境地，文本里写成「传说」「古籍残载」。
- **没有飞升、没有天门**。渡劫过了就是真仙，仍在五域，寿元极长，可以活过纪元。
- 凡人武道另有「品」（沈砚七品、韩彪八品），只用于描写凡人高手，不做系统。

## 6 轮回与前世手札（核心爽点，见 B24）

- 死亡 → 魂识回到第 1 年。**世界重置，记忆保留**。
- **前世手札**（存在跨世存档里）：只记主角亲历或确知的大事——某年、某地、发生了什么、结局如何。新一世在手札里能看到。
- 大事再次发生时提示「前世所记，今日应验」；凡是在手札里有记载的大事，事件里会多出「先知」选项（提前囤粮、提前修堤、提前报信……）。
- 改写成功（结果与基准走向不同）提示「历史已改写」，记入「本世改写」。
- 主动结束一世：结丹以上可「兵解入轮回」，按此生作为结算。
